# ULTRON Mark 3

A clean-generation personal operating assistant built from the Mark 2 foundation without mutating Mark 2.

## Principles
- persistent context over isolated chat turns
- working memory + episodic memory + semantic memory + commitments + decisions
- explicit plan -> execute -> verify -> recover lifecycle
- live model/provider inventory and observed performance history
- proactive event loop with attention-aware notifications
- unified text and voice state machine
- performance-governed globe interface
- readable UI typography: Inter/Manrope for interface copy, JetBrains Mono only for telemetry/code
- deterministic tests and health checks at every integration boundary

Mark 3 is intentionally developed in this folder so Mark 2 remains recoverable.
