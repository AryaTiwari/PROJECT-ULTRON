# ULTRON Mark 3

Clean-generation personal operating assistant. Mark 2 remains untouched and recoverable.

## Core pillars
- persistent working, episodic, semantic and strategic memory
- commitments, decisions, projects and goals
- plan -> act -> verify -> recover agent loop
- live model/provider catalog and empirical model performance
- proactive event loop with attention-aware notifications
- unified text/voice lifecycle with expressive speech orchestration
- performance-governed globe interface
- readable typography: Inter/Manrope for interface, JetBrains Mono only for telemetry/code
- deterministic integration and smoke tests
