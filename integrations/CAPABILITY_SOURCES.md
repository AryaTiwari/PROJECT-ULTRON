# ULTRON Mark 2 Capability Sources

## PROJECT-ULTRON
Canonical application, identity, orchestration, memory policy, safety policy, and stable interface contract.

## MULTI-AI-BRAIN / OmniRoute
Model gateway only. ULTRON owns task classification and high-level routing policy; OmniRoute owns provider protocol compatibility and provider-side fallback.

## BRAHMA-BODY
Selective source for voice, browser, computer-control, and desktop-assistant capabilities after they are wrapped behind ULTRON tools.

The Brahma Electron application shell is not part of the final ULTRON UI.

## JARVIS-BODY / OpenJarvis-derived material
Use architecture and reusable local-AI/agent/memory/learning concepts where implementation is present and compatible. Do not make ULTRON depend on missing or duplicated application shells.

## Integration rule

Every imported capability must enter ULTRON through a stable adapter/tool contract. Donor projects must not own ULTRON's personality, memory authority, Guardian, Critic, or Executor policy.
