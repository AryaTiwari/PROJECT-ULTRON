# Multimodal artifacts
Read attachments from their supplied local runtime paths. Confirm file type from content where practical.
Create the requested native artifact directly, then render or inspect it before delivery. Use readable structure, strong hierarchy and platform-correct dimensions.
For PDF/DOCX/Sheets outputs, preserve tables, links and headings. For audio, return a valid native container. For video, inspect codec, dimensions, duration and file size.
Never claim an artifact exists until the file is present and validated. Return a usable local path or external URL plus concise verification evidence.
