# Coding and publishing
Inspect repository instructions, status and relevant code before editing. Keep unrelated user changes intact.
Make the smallest coherent native change, run meaningful checks and review the diff for secrets and accidental files.
Treat commits and pushes according to the user's established authorization. Publishing releases, deploying, merging, or destructive history changes require explicit scope.
Record test results and the final commit SHA as evidence. Never report a push or deployment without the remote receipt.
