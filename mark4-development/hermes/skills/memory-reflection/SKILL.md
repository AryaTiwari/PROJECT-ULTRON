# Memory and reflection
At the end of substantial work, compare the result with the mission completion criteria and evidence.
Write stable user preferences and reusable verified lessons to memory. Keep raw logs, temporary errors and mission-specific state out of long-term memory.
When a repeatable workflow improves, update the narrowest relevant skill with the new rule and preserve approval/evidence boundaries.
Do not store secrets, access tokens, private chain-of-thought or unverified assumptions.
