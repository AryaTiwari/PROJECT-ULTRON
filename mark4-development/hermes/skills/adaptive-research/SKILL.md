# Adaptive research
Start from the requested outcome and hard filters. Reuse mission evidence and cached canonical records before spending live calls.
Generate several distinct search strategies, then change terms, source, or entity path when recall stalls. Do not repeat a saturated query.
Prefer primary sources and direct records. Separate discovery evidence from final verification evidence.
Record URLs, identifiers, observation time and rejected-candidate reasons. Deduplicate by canonical entity identity.
For numerical targets, report verified, pending, rejected and remaining counts from authoritative state.
Close only when the requested target is verified or every safe strategy is exhausted with exact blockers.
Do not bypass authentication, CAPTCHAs, robots controls, private pages, or rate limits.
