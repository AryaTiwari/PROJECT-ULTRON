# ULTRON durable memory

This file is the curated long-term memory layer for Project ULTRON Mark 4.

- Store durable preferences, verified operating facts, reusable lessons and stable business context.
- Keep mission state, evidence, raw tool output and temporary execution details in their native stores instead of duplicating them here.
- Never store secrets, access tokens, private chain-of-thought or unverified claims.
- Prefer a concise fact with its source or date over a vague narrative.
- Revise stale facts when stronger evidence arrives.
